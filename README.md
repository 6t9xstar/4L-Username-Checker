🛡️ MALIK – Instagram Username Hunter

A terminal-based Instagram username availability checker with 4L / 5L / 6L modes, built for Kali Linux, Termux, and Pydroid3.
Designed with hacker-style visuals, sound alerts, and Telegram notifications.


---

✨ Features

🔍 Check Instagram username availability

🔢 Supports 4-letter, 5-letter, and 6-letter modes

🎨 Hacker-style Kali Linux banner

🔔 Sound alert on hit

📩 Telegram bot notification for available usernames

📱 Works on:

Kali Linux

Linux

Termux (Android)

Pydroid3 (Android)

⚙️ Requirements

Internet connection

Telegram Bot Token

pip install requests
